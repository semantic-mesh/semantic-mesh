# Semantic Mesh

**Autonomy within domains. Explicit meaning at their boundaries.**

Semantic Mesh is an emerging, domain-driven approach to making the meaning,
ownership and services of business domains understandable to people and software.
A domain publishes a versioned Semantic Domain Contract describing what it means,
owns, offers, requires and guarantees. These contracts connect autonomous domains
without imposing a single enterprise-wide domain model or technology stack.

This initiative is in its founding stage. The reference model is a draft; a
released contract specification and conformance implementation do not yet exist.

## Participate

Open an [issue](https://github.com/semantic-mesh/semantic-mesh/issues) with a use
case, counterexample or concrete improvement. To propose an edit, fork this
repository, create a branch in your fork and open a pull request against `main`.
Repository write access is not needed to propose a contribution.
English is the language for all repository content and project contributions.
Check the licensing status before submitting material for redistribution.
