# Licensing status

No project license has been adopted yet. Public repository access alone does not
make the materials openly licensed. The project should not announce an open-source
release until explicit licenses and their scope have been reviewed and committed.

The founding proposal is to evaluate CC BY 4.0 for original explanatory prose and
Apache-2.0 for software and schemas. This is a proposal, not a license grant.
Specification prose, examples, third-party material and contribution terms need
an explicit scope decision before publication. Existing source rights must be
checked before importing the whitepaper or other documents.

Until then, prefer feedback and issue discussion over contributions that require
redistribution permissions. License adoption will be recorded in a separate PR
with complete license texts, file coverage and attribution rules.
