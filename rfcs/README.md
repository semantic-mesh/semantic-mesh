# Requests for comments

Use an RFC for changes to concepts, principles, governance or future contract
semantics. Start with an issue, then copy [the template](0000-template.md) to a
descriptive file and open a PR. Assign a numeric identifier when the maintainer
accepts it for review. Drafts may change freely during review.

States: Draft → In review → Accepted or Rejected. An accepted RFC can later be
Superseded by a linked RFC. Acceptance records a decision, not implementation.
Follow the comment period in [governance](../GOVERNANCE.md), and record rationale,
objections and implementation links before merging the decision.
