# Proposed Semantic Mesh principles

Status: working proposal derived from the founding discussion. These seven points
are not a transcription or replacement of the author's twelve DCA principles.
Reconcile them with the reviewed whitepaper before a formal publication.

1. **Domain authority.** Meaning and ownership stay with the responsible domain
   and bounded context.
2. **Explicit boundaries.** Publish selected meaning, services, responsibilities
   and constraints through versioned contracts.
3. **Interoperability through mappings.** Preserve contextual differences instead
   of forcing every domain into one enterprise model.
4. **Benefit before modeling overhead.** Reuse maintained domain artifacts and
   demonstrate discovery or change-impact value in a small use case.
5. **Human accountability.** Automation can propose semantics; accountable people
   approve meaning and publication.
6. **Proportionate federated governance.** Agree on a small shared contract core
   and automate checks where they provide evidence; leave local choices local.
7. **Replaceable technology.** Keep the conceptual model independent of a graph
   store, runtime, cloud, AI model or registry implementation.
